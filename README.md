# ES26205: Engineering Robotics 🤖

A peer-to-peer repository for practical codes, simulation scripts, and notes for the **ES26205: Engineering Robotics** course. Built by students, for students to share solutions and collaborate.

## 🚀 How to Use

1. **Clone or Download:**
   ```bash
   git clone https://github.com/AishaChunawala/es26205-robotics-labs.git
   ```
2. **Open the `.ino` file** directly inside the Arduino IDE to view, compile, and flash it onto your board.
